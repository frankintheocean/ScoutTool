# Source reference

The independent zero-viewer discovery module follows the public API and search behavior of [Jack Kingsman’s Nobody.live](https://github.com/jkingsman/Nobody.live), examined at commit `d099772b96b04daeb9b843ce092a9e0796ff0062`. No crawler, PostgreSQL schema, frontend assets, or additional runtime dependencies were imported.
